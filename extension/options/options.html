Local Translator 설정

엔진

번역 품질이 가장 좋았던 로컬 모델입니다. 번역 중 메모리를 약 3GB 쓰고, 5분 동안 쓰지 않으면 해제됩니다. 먼저 Ollama를 설치하고 ollama pull translategemma:4b 를 실행하세요. 버튼은 값만 채우며 저장을 눌러야 적용됩니다.

Localhost 엔진

로컬 모델 서버에 한 번에 보내는 요청 수입니다. 올리면 빨라질 수 있지만 메모리를 더 씁니다.

DeepL (선택, 외부 전송)

DeepL을 엔진으로 선택하면 번역할 페이지 텍스트가 DeepL 서버로 전송됩니다. 기본 엔진은 이 Mac 안에서만 처리합니다.

키는 이 기기에만 저장되며 동기화되지 않습니다. 비워 두고 저장하면 기존 키를 유지합니다. 키가 :fx로 끝나면 무료 API, 아니면 Pro API를 씁니다.

번역 옵션

켜면 content/extra.js가 추가로 주입됩니다

용어집

한 줄에 원문 => 번역 (예: safety car => 세이프티카). 번역 전에 원문의 해당 단어를 바꿔서 보내므로 항상 이 표기로 나옵니다. 최대 500개, 저장 후 해당 문장만 다시 번역됩니다.

자동 번역 사이트

한 줄에 호스트 하나. example.com 은 서브도메인 포함, docs.example.com 은 정확히 일치.
